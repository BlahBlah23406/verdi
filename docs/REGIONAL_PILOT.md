# Verdi regional pilot

The existing Cedar demo now covers six fictional households in King and Pierce counties. The same loopback server and SQLite database hold each household's connection states and records. Choose a household at [the local demo](http://127.0.0.1:8788/), then choose **Set up your sources**. Select the sources you want and approve the selection once. The server continues collecting after the browser closes. You can expire, reconnect or disconnect a source individually.

## Household scenarios

All households have simulated bank transactions, electricity and ORCA activity. The values and people are fictional. Utility footprints, routes, stops and representative adult fares come from provider and agency sources checked November 26, 2026.

## Provider access and existing sandboxes

| Source | Path and current status |
|---|---|

The vendor's Sandbox supports Link, reusable test users, custom transactions and test webhooks. Verdi's local fixture exercises the same parser with pending replacement, refunds, modified transactions and pagination retries. Self-serve Link and per-connection token storage are pending. Its mock authorization disables after the first extraction, so use its statement-generation test action to exercise later bills. Residential coverage and recurring availability for PSE, Seattle City Light and Tacoma Power remain unverified. The live [coverage catalog](https://dashboard.arcadia.com/providers) distinguishes statements from interval readings. [Arcadia Sandbox](https://docs.arcadia.com/docs/sandbox-testing) · [Coverage guide](https://docs.arcadia.com/docs/provider-coverage) |
| Direct utility data | PSE publishes a combined residential bill and an automated EnergyCAP path for eligible commercial, industrial and multifamily benchmarking. Automated third-party residential access remains pending for these three utilities. Tacoma Power electric and PSE gas need separate account authorizations. The workspace had no configured provider credentials for the credentialed sandbox tests. The six-household walkthrough uses the existing local simulator. Vendor-hosted sandbox calls and live household feeds still need validation.

## One setup flow and ongoing collection

Use one Verdi screen to select the desired sources. The demo approves the selections in a single request, `POST /api/demo-authorize`, and validates every selection before applying any change. In production, open the relevant provider's consent flow for each account that requires it. The provider's developer API credentials and the resident's account authorization are separate. Persist the provider account and granted scopes per source, and collect automatically using webhooks or scheduled server-side sync. Show when access needs renewal and allow independent disconnection. Keep recurring uploads outside the connected-source workflow.

The [existing native phone capture](../lib/product/pilot_phone_capture.dart) is a separate option for estimated trip summaries. It samples location while the mobile app is active. Coordinates stay on the phone in memory, and the user reviews the trip mode before sending its summary. Public service data can add context, while personal ride history depends on consented evidence.

## Verification

- [HTTP integration tests](../backend/test_redmond_http.py) cover city-specific records, invalid selection rollback, household isolation, separate Tacoma gas and power, supporting charger evidence, expiry and restart persistence.
- [Flutter tests](../test/redmond_demo_app_test.dart) cover grouped approval, cancellation, single-source reconnect and delayed responses while switching households.
- Chrome verified all six cities, one request for five Sammamish sources, continued collection with the browser closed, and retained records after expiry and disconnect. A mobile-width Chrome session also recovered the selected Seattle household after a server restart. A copy of the earlier Cedar database kept its existing connection and history rows when the new households were added.
- Vendor verification should start with Plaid Sandbox and Arcadia's documented fixtures, then Smartcar and Enode read-only test assets. For a live connection, verify the exact account or device type, returned fields, repeat delivery without uploads, provider-side revocation and recovery after expiration.
